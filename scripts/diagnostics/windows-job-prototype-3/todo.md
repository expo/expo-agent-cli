# Prototype checklist

- [x] Scope the decision the prototype exists to make: which layout, which interaction, which density, or for an empirical fork which behavior, timing, or approach. No decision means no prototype. Route to Feature.
- [x] Gather references when the design space is open. Search for prior art, summarize a moodboard of themes, palettes, and layouts, let the user pick directions before building. Skip when the direction is set.
  - skip: Root selected the bounded lifetime-census contract and owns the independent review.
- [x] Build throwaway in an isolated scratch dir, separate from production source. For a visual decision, vanilla HTML/CSS/JS or the lightest stack that renders the idea, CDN deps, a dev server with hot reload. For a behavioral or timing decision, the smallest script that exercises the question. No production framework, no tests, no abstractions.
- [x] When comparing alternatives, build them behind one switcher (buttons or a keypress), each variant labeled. This is the **exhaust-the-design-space** principle skill made cheap.
  - The controller labels the lifetime census and rejected count-only comparison separately.
- [ ] Verify on the matching surface. For a visual decision, screenshot each variant via the driver skill and drive the interaction. For a behavioral or timing decision, observe the thing you are deciding by logging the timing, printing the output, or watching the render. The observation is the test here, not an assertion.
  - Root owns native Windows dispatch. Local Node syntax checking is not native evidence.
- [ ] Present alternatives, tradeoffs, and a recommendation. The output is the decision plus the throwaway artifact, not shippable code. Hand the chosen direction to **Feature** (or `architect` for the shape) for the real build.
  - Product work remains frozen until root accepts native results and the remaining contract premises.

The collector is one private helper-owned census of retained process handles. IOCP only suggests PIDs to authenticate. Current membership supplements discovery. A sticky coverage fault, exact retained waits, and a fresh lifetime total are separate state fields. The decision is whether this collector succeeds on bounded real local commands while refusing omitted or ambiguous identities.

The throughput checkpoint keeps all native state in the existing helper and reuses the established raw-stdio/private-control transport. Root owns Git and hosted actions. This directory owns the throwaway payload only. The first native run decides whether further experiments earn their cost.
