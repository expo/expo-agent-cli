# expo-agent-cli

npm alias for [`@expo/agent-cli`](https://www.npmjs.com/package/@expo/agent-cli).

`bunx expo-agent-cli@2.0.0` runs `@expo/agent-cli@2.0.0`. The version of this package is the version of the CLI that runs. Prefer `npx @expo/agent-cli` in docs, help, and `Try:` lines.

This package has no dependency on `@expo/agent-cli`. Publishing `@expo/agent-cli` also publishes this alias at the same version and dist-tag.

Versions before 1.0.0 were an unofficial Expo docs CLI. 1.0.0 is Expo's alias. A `^0.6` install stays on the old CLI.
